# Merim Malkic — Engineering Portfolio

Responsive static portfolio built from the user's supplied portfolio PDF, CAD renders, FEA screenshots, prototype photographs, and autonomous-drive footage.

## Preview locally
Open `index.html` in a browser. The video is included in `assets/first-autonomous-drive.mov` using the original uploaded MOV file. Browser support for HEVC video varies; if playback is unavailable, use the separate original video file or provide an H.264 MP4 version.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `merim-robotics-portfolio`.
2. Upload the contents of this folder (not the ZIP itself) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. GitHub will provide the public website URL after deployment completes.

The site is static and does not require a build step.
